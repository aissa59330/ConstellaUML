## Contextuels (quick-edit et explorateur)

| Contexte | Action | Raccourci |
|---|---|---|
| Diagramme / explorateur | Quick-edit / renommer | `Entrée` ou double-clic |
| Quick-edit de classe | Ajouter un attribut / une opération | `Ctrl+Entrée` / `Ctrl+Shift+Entrée` |
| Quick-edit d'attribut, d'opération ou de littéral | Ajouter en dessous / supprimer / monter / descendre | `Ctrl+Entrée` / `Ctrl+Suppr` / `Ctrl+↑` / `Ctrl+↓` |
| Textes multilignes | Nouvelle ligne | `Shift+Entrée` |
| Diagramme | Déplacer de 1 px / d'un pas de grille | flèches / `Shift`+flèches |
| Diagramme | Outil de sélection | `Échap` |
| Console de script | Exécuter / nouvelle ligne / historique | `Entrée` / `Shift+Entrée` / `↑` `↓` |
